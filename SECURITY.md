# Security policy

## Supported versions

Security fixes are applied to the latest commit on `main`. The project has not
yet made a stable release, so older snapshots are not maintained separately.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting page:

<https://github.com/anvajhhf/wechat-ai-secretary/security/advisories/new>

Do not include credentials, OAuth tokens, private messages, voice recordings,
Vault contents, or production databases in a public issue. If a credential may
have been exposed, revoke or rotate it first, then report only the minimum
redacted evidence needed to reproduce the problem.

Please include the affected revision, impact, reproduction conditions, and a
suggested mitigation when available. Acknowledgement is normally provided
within seven days, but no fixed resolution date is guaranteed.

## Scope

Reports about the repository's code, installation scripts, local data
isolation, message routing, or credential handling are in scope. Account,
availability, or policy issues in third-party services should be reported to
the corresponding provider.
